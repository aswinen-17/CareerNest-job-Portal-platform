# CareerNest - Job Portal Platform

A full-stack job portal platform, the user-friendly job portal connecting job seekers and recruiters seamlessly

---

## Features

- User registration and login for seekers and recruiters
- Profile picture upload during signup
- Add company and Job posting management for recruiters
- Job browsing and application for seekers
- Responsive UI built with React
- Backend API with Node.js, Express, and MongoDB
- Image upload support with Cloudinary integration

---

## Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB, Mongoose
- **Image Upload:** Cloudinary
- **State Management:** Redux Toolkit
